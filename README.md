## Cómo publicarlo (GitHub Pages, sin terminal)

1. Sube este repo a GitHub (si no lo hiciste ya vía la interfaz web: **Add file → Upload files**, arrastra `index.html` y `README.md`).
2. Entra a **Settings → Pages** del repo.
3. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`. Guarda.
4. En 1-2 minutos GitHub publica el sitio en:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`

   Si el repo se llama exactamente `<tu-usuario>.github.io`, la URL queda limpia: `https://<tu-usuario>.github.io/`.

## Actualizar el contenido

Edita `index.html` directamente desde GitHub (lápiz ✏️ en la esquina del archivo) o súbelo de nuevo reemplazando el existente. Los cambios se publican solos en 1-2 minutos.
